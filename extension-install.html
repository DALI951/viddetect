viddetect Chrome Extension

Once installed, whenever you visit a YouTube mix, the extension automatically sends the exact playlist data to viddetect. No manual steps needed.

Open chrome://extensions
  1. Click the button above to open the Extensions page
  2. Enable "Developer mode" (toggle in the top-right corner)
  3. Click "Load unpacked"
  4. Navigate to and select this folder:
    C:\Project\viddetect\extension
  5. The extension is now installed. Go to any YouTube mix — you'll see a toast: Sent N videos to viddetect
  6. Switch back to viddetect and click "Browse" on the mix — entries will match exactly
The extension only runs on YouTube pages and only sends playlist data from window.ytInitialData to localhost:3001. No data is sent anywhere else. Source code is in extension/content.js.
